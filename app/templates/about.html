About Phishinator

Phishinator is an email security analysis platform designed to dissect suspicious .eml files. By combining rule-based heuristics, VirusTotal multi-link intelligence, and OpenRouter AI summarization, it provides instant threat clarity to defenders and users.

Core Functions

  • • Parses full MIME structures, Return-Path, and envelope headers.
  • • Extracts embedded links & queries VirusTotal v3 security database.
  • • Calculates heuristic risk score (0-100) based on threat patterns.
  • • Generates OpenRouter AI executive security summary.

Threat Intelligence

Phishinator integrates directly with VirusTotal's URL API to verify whether linked domains are active malware hosts, phishing landing pages, or credential harvesters, providing enterprise-grade signal analysis.

Privacy & Security

Files are processed in memory and temporary storage, then immediately deleted after evaluation. IP rate-limiting ensures operational stability without storing sensitive user payload data.

Detection Vectors

Key signals evaluated by the Phishinator scoring engine.

Sender Mismatch

Identifies discrepancies between display names, From addresses, and Return-Path routing.

Language Urgency

Detects social engineering triggers demanding immediate password resets or account verification.

Malicious Attachment Cues

Flags attached payloads and archives commonly used to deliver trojans or ransomware.
