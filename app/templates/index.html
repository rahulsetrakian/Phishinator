Frequently Asked Questions

Everything you need to know about how Phishinator operates.

What does Phishinator check?

It parses the email headers, sender domain reputation, embedded URLs via VirusTotal, attachments, and body language to compute a heuristic risk score.

How does VirusTotal verification work?

Phishinator extracts all clickable links from the message body and queries the VirusTotal v3 API to check if any domain is flagged by global security engines.

Are files stored on the server?

No. Uploaded files are evaluated in real-time and immediately deleted from server storage upon completion of the report.

What is the rate limit?

To preserve VirusTotal quota and API bandwidth, uploads are rate limited per IP address. Excessive requests will return a friendly 429 wait screen.

How is the AI summary generated?

Phishinator sends anonymized headers, rule findings, and VirusTotal flags to OpenRouter LLM to synthesize an executive security summary.

What formats are supported?

Phishinator accepts standard .eml files exported from Outlook, Thunderbird, Apple Mail, or webmail clients.
